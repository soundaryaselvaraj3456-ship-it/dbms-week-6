# E-Commerce Review Management System

## Description

This project uses SQL to manage and analyze customer reviews in an e-commerce database.

## Database

`EcommerceDB`

## Tables Used

* **Review** – Stores customer reviews and ratings.
* **Product** – Stores product details.
* **Customer** – Stores customer information.

## Operations Performed

* Update and delete reviews.
* Retrieve product and customer reviews.
* Calculate average product ratings.
* Count total reviews for each product.
* Identify highly rated and low-rated products.
* Analyze customer ratings using aggregate functions.

## SQL Concepts Used

`SELECT`, `UPDATE`, `DELETE`, `JOIN`, `GROUP BY`, `ORDER BY`, `HAVING`, `COUNT()`, and `AVG()`.

## Conclusion

This project demonstrates how SQL helps manage customer reviews, analyze product ratings, and understand customer satisfaction.
